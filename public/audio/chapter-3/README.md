# Chapter 3 audio slots

현재 네 파일에는 타임라인 길이에 맞춘 무음 플레이스홀더가 들어 있습니다. 같은 이름으로 실제 녹음 파일을 덮어쓰면 됩니다.

- `bathroom-room-tone.mp3` — 수도관·형광등이 거의 들리지 않는 욕실 룸톤
- `bedroom-night.mp3` — 밤의 전기음과 먼 바람
- `shadow-whisper.mp3` — 오리지널 속삭임 + 보코더 레이어
- `school-street.mp3` — 웰링턴 아침 거리 환경음

그림자 목소리는 특정 작품의 언어나 연기를 모사하지 않고, 짧은 인간 속삭임과 20–30ms 먼저 오는 낮은 보코더 레이어를 조합합니다.
