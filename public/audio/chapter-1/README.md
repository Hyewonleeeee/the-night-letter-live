# Chapter 1 live ambience

- `exterior-wind.mp3` (00:24) — 차가운 외부 바람과 아주 먼 종
- `interior-room.mp3` (01:12) — 창문 안쪽의 먹먹한 방 공기와 빗소리
- `letter-whoosh.mp3` (00:10) — 00:24 편지 비행에 맞춰 왼쪽에서 오른쪽으로 이동하는 종이 바람
- `paper-close.mp3` (00:18) — 00:34 편지를 집고 뒤집고 여는 가까운 종이 마찰
- `letter-taps.mp3` (00:20) — 00:52–01:12 다섯 문장 노출에 맞춘 불규칙한 타닥거림
- `time-shift.mp3` (00:34) — 다음 날 할로윈 밤으로 넘어가는 공기 변화
- `ritual-air.mp3` (01:06.35) — 의식 준비의 고요한 방, 세 번의 천 마찰과 낮은 실내 공명
- `threshold-drone.mp3` (00:29.65) — 주문 직후 02:52.35부터 들어오는 43 Hz 저음 드론

각 파일은 `/live`의 `01_invitation` 챕터 실행과 전역 플레이어 타임라인이 같은
절대 시간을 사용합니다. `interior-room`, `time-shift`, `ritual-air`는 구간이 겹쳐
크로스페이드되므로 장면 경계에서 갑자기 끊기지 않습니다. 동일한 파일명과 길이를
유지하면 공연용 녹음으로 교체할 수 있습니다.

현재 파일은 외부 샘플 없이 로컬에서 합성한 교체용 초안입니다. 다시 만들려면 프로젝트
루트에서 다음 명령을 실행합니다.

```bash
npm run render:chapter1-audio
```
